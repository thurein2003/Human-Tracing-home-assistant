# Native FreeCAD simulation package

## Why Simulation was disabled in the requested file

I opened the exact on-disk `CAD/EyeTrace_Final_Assembly.FCStd` in FreeCAD 1.1.4. It contains 80 objects, but no `Assembly::AssemblyObject`, no `Assembly::JointGroup`/Joints folder, no joints, and no grounded component. It is a static geometry document. Therefore it cannot run native Assembly simulation as saved.

The installed FreeCAD Assembly workbench supports Simulation. Its command is enabled only while an assembly is active for editing and the assembly contains at least one dynamic joint type (Revolute, Slider, or Cylindrical). A visible Joints folder in another open or unsaved session could be an empty group or contain only Fixed joints; either case still leaves Simulation disabled. The actual on-disk file inspected here has no Joints folder at all, so the folder seen in the UI is from a different in-memory state/document or revision.

## Corrected separate assembly

Open `EyeTrace_Final_Assembly_Native_Simulation_r02.FCStd`. It is made from the existing audit geometry and leaves the source file unchanged. Its native Assembly contains seven linked rigid groups and these joints:

- Grounded base
- Fixed: pan servo housing to stationary base
- Revolute: pan output about vertical Z axis through `(0, 0, 35) mm`
- Fixed: pan star horn to pan rotor
- Fixed: tilt servo housing to pan rotor
- Revolute: camera cradle about horizontal X axis through `(-41, 0, 78) mm`
- Fixed: tilt star horn to camera cradle

This gives exactly two independent revolute coordinates. The pan servo housing is grounded through the base. The tilt housing follows pan rotation via its Fixed joint to the pan rotor and remains fixed relative to the camera cradle during tilt. Each horn follows the moving output through its Fixed joint to its driven structure. The solver returns 0.

Rigid attachments for the remaining screws, covers, supports, and camera components are grouped in their respective rigid links, rather than represented by redundant pairwise joints.

## Saved native simulations

The assembly has a `Simulations` folder with three FreeCAD Assembly simulation objects. Each simulation generated 52 frames and was checked at a quarter-cycle using actual component placements:

| Saved simulation | Pan | Tilt | Result |
|---|---:|---:|---|
| Pan only - native motion | ±60 deg | fixed | Pan rotates; cradle has no tilt relative to pan rotor |
| Tilt only - native motion | fixed | ±25 deg | Pan rotor stays fixed; cradle tilts |
| Combined pan and tilt - native motion | ±45 deg | ±20 deg | Both axes rotate |

Motion formulas use radians, as described by the installed Assembly simulation command. They are visualization inputs, not servo PWM calibration. Simulation steps are generated by FreeCAD when opened/run; they do not certify physical fit, collision-free hardware travel, or servo compatibility.

## FreeCAD menu steps to play a saved simulation

1. Open `EyeTrace_Final_Assembly_Native_Simulation_r02.FCStd` in FreeCAD 1.1.4.
2. Select the **Assembly** workbench.
3. In the Model tree, double-click **Eye Trace - native two axis assembly simulation** to activate/edit the assembly. Expand **Joints** to see GroundedBase, the four Fixed joints, and PanRevolute/TiltRevolute. The Simulation command should now be enabled because dynamic joints exist.
4. Expand **Simulations** and double-click the simulation you want: **Pan only - native motion**, **Tilt only - native motion**, or **Combined pan and tilt - native motion**.
5. In the Simulation task panel, click **Run Kinematics** and wait for frame generation.
6. Use the panel's forward play control (right-facing triangle) to play. The same panel has stop, step, and frame slider controls.

If you want to create another simulation instead, activate the assembly as in step 3, then choose **Assembly > Simulation** (or its Simulation toolbar button). Add an Angular motion and select the desired revolute joint.

## Evidence and limitations

- Reopened with FreeCAD 1.1.4 Python interface: `Assembly::AssemblyObject`, Joints group, all seven native joints, and all three native Simulation objects are present.
- Solver return: `0`.
- Single-axis relative-transform checks: pan-only changes pan and leaves tilt relative angle fixed; tilt-only leaves pan fixed and changes tilt; combined changes both.
- Results: `native_simulation_validation.json`.
- Build macro: `Create_Native_Simulations.FCMacro`.
- Actual CAD quarter-cycle captures: `pan_native_quarter.png`, `tilt_native_quarter.png`, `combined_native_quarter.png`.
- The earlier `EyeTrace_Final_Assembly_Native_Simulation.FCStd` in this folder is a superseded first draft. Use the `_r02` file above.

The horns, spline interface, servo clone dimensions, idler preload, camera envelope, and cable routing are not physically verified. The audit's prior finding remains: physical motion is unverified, and the assembly is not approved for full ABS printing solely on this simulation result.
