# Editable CAD and regeneration
Open EyeTrace_Final_Assembly.FCStd in FreeCAD1.1.4. This is a native component BRep document with Boolean camera features and expressions, not an Assembly-workbench joint solver or entirely sketch-constrained model.49 active tagged components include hardware and explicitly named uncertainty volumes. The STEP includes reference keepouts; do not print all STEP solids.

SOURCE_SNAPSHOT/Integrated_Source.FCStd preserves the selected prior geometry, so CAD generation does not require the earlier folders. parameters.json is the portable input. Camera21x16 center spacing is locked to the user's nominal. Camera outer size/hole diameter/lens/offsets and rear/ribbon reservations are separate. Horn lengths/angles/widths/hub/web/socket envelopes and pocket allowance/depth are explicit provisional inputs; smooth socket/bore values are not exact spline or thread specifications.

Use bundled FreeCAD Python: `& 'D:\App files\bin\python.exe' .\CAD\generate_final.py` from the final project root. The script opens the preserved source and rebuilds the final working document. Camera standoff height/OD and screw length are rebuilt as a matched stack; changing standoffs in isolation in the GUI does not rebuild fixed spacer/bolt BReps. Use parameters.json plus generation script for those changes, and rerun all tests. Native camera envelope properties remain independently editable. The script rejects insufficient nominal camera screw projection.

Default generation was checked to preserve ALL49 nominal component BReps within0.001mm3 symmetric difference, including changed parametric representations. Measured changes will intentionally differ and require full revalidation. Ear references/brackets remain explicit sourced nominal BReps; a clone with different tab/case geometry requires measured bracket/reference revision, not model scaling. Source dimensions/confidence and unresolved fit are in DOCUMENTATION/DIMENSIONAL_AUDIT.csv.

After regeneration run TESTS/run_all.ps1 with the installed FreeCAD Python path. Tests never certify physical fit. Regeneration/exports write only this final project, never earlier candidates. Source generation and validations are included; original source builders remain unchanged in the earlier revisions, with exact feature traceability and hashes here.

Retained bracket ear datums are sourced fixed BReps, not a fabricated universal SG90 standard. If either real clone differs, revise those measured features and their reference together, then rerun all alignment, access, collision and export tests. Do not compensate by scaling a servo or mounting plate.
